# AI Learning Assistant

An NLP-Based Educational Chatbot for Beginners.

## Project Overview

This chatbot helps students learn about:

- Artificial Intelligence
- Machine Learning
- Deep Learning
- Python
- Data Science
- Career Guidance

## Technologies Used

- Python
- NLTK
- Scikit-Learn
- Google Colab
- Gradio
- Matplotlib

## Features

- Question Answering
- AI/ML Learning Support
- NLP Processing
- Educational Guidance
